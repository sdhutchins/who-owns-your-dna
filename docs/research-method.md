# Research and review method

The public methodology page is the canonical audience-facing explanation. This document describes the repository workflow that supports it.

## Source review

Review begins with official statutory text, legislative material, regulations, agency publications, court opinions, or government archives. Secondary sources may identify candidates or explain context, but they do not replace available primary text.

## Candidate changes

Future monitors may retrieve candidate changes from Congress.gov, the Federal Register, state legislatures, state codes, and agency notices. Candidate output stays outside the verified dataset until human review confirms the identity, status, dates, scope, source, and summary.

## Corrections

A correction should update the affected fields, add a dated history event, and increment the record version when the public interpretation or provenance changes materially. The pull request should explain whether the correction changes the source, legal status, summary, or only metadata.
